## ✨ First release v0.1.0

- Simple markdown to write.
- Built-in plotting and fitting.
    - Optimized for nuclear or high energy physics data analysis, histogram/fitting, data with errors, error bands plots
    - Special `Standard Model`, `Feynman Diagram`, `Periodic Table` plotting with fancy animations
- Built-in PDF format plot support
    - `p` to PDF model to check original PDF files when the slide has PDF plots
- Built-in table support
    - markdown and math support
    - animation by rows, columns and cells support
- Presenter and Viewer rich-controls
    - sportlight (`s`), laser (`l`), annotation/eraser (`a`/`e`), TOF (`t`)
    - overview (`o`/`0`), filmstrip (`v`)
    - more to check by `h` or `?`, available controls in Viewer are different with/without Presenter open
- Animation-rich.
    - Staged animation with `→`/`←`
    - Automatic animations with `Space` key to pause/play
- Live update when editing
    - Live update slides during editting the markdown source when saving
    - Live theme updating
    - Live aspect ratio updating
    - A lot more
