## ✨ Release v0.3.0

NeoPresent 0.3.0 focuses on richer visual design, more expressive scientific animation, and finer deck-wide control.

### Themes and visual styling

- Expanded the creative and glass theme families with more distinctive layouts and decoration.
- Added deck-wide and per-slide heading-panel position, width, and padding controls while preserving theme defaults.
- Added deck-wide glass and shadow controls for plots, headings, footers, blocks, and other supported content.
- Refined drop, contact, and curved shadows, including perspective and inward/outward curvature controls.
- Added responsive glass styling for populated footer regions only.

### Plots and animation

- Added in-place, reversible `morph` transitions for compatible plot data, axes, functions, and fitted curves.
    - Morph animation works for some built-in plot types
- Added `chart-trim` and `chart-padding` controls for tightening plot wrappers around circular and sparse charts.
- Fixed clipped legends in donut and radar plots and audited other built-in chart layouts.
- Improved categorical axis handling, point motion, reverse transitions, and replacement-block positioning.

### Authoring and presenting

- Expanded syntax highlighting across major programming-language families and improved code contrast and indentation.
    - C#, Go, Java, VB, SQL, Rust, Pascal, PHP, Fortran, Ruby, Swift, Perl, etc.
- Refined live chalk annotations with denser, varied pores and consistent rendering in viewer, presenter, and export.
- Updated the settings references so the new theme, glass, shadow, chart-layout, magnifier, morph, and annotation controls are discoverable.
